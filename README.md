# Turtle Courier

Репетиция «Новой высоты» для TurtleBro в Webots R2025a и ROS 2 Humble.
Поле 3,40 × 3,44 м реконструировано по фотографиям. Есть шесть парковок,
центральная улица, боковые заезды, красные корпуса, синий Т-образный корпус и
жёлтые кубы. Размеры приблизительные.

```bash
cd ~/zed/ros2/turtle-courier
docker build -t turtle-courier:humble .
mkdir -p results
docker run --rm --init --user "$(id -u):$(id -g)" -e HOME=/tmp -e USER=robot \
  -v "$PWD/results:/results" turtle-courier:humble
```

По умолчанию старт и цель выбираются случайно и всегда различаются.
`--seed 17` повторяет жеребьёвку и случайную ориентацию. `--yaw-offset 180` задаёт разворот вручную. Можно явно указать
`--start 21 --goal 23`. Тренировочные ID: 21, 22, 23, 25, 26, 27.
На фото крупным планом читается ArUco 27 из семейства 4×4. Остальные ID
и координаты сверяйте с вашим экземпляром поля. Настройки лежат в `field.py`.

Запуск с окном под X11/XWayland:

```bash
docker run --rm --init --user "$(id -u):$(id -g)" -e HOME=/tmp -e USER=robot \
  -e DISPLAY -v /tmp/.X11-unix:/tmp/.X11-unix:ro \
  -v "$PWD/results:/results" turtle-courier:humble --gui --start 21 --goal 23
```

Если сеанс требует Xauthority, передайте контейнеру файл текущей X11-сессии
только для чтения и задайте `XAUTHORITY` на его путь внутри контейнера.
После финиша окно остаётся открытым. Для нового заезда закройте его и
повторите команду. `--clear` убирает дополнительный куб с центральной дороги
и оставляет шесть кубов на островках, как на фото.

`navigate.py` узнаёт старт по крупной ArUco в кадре, останавливает поиск и по свежему кадру привязывает относительную
одометрию к парковке и строит кратчайший путь по графу дорог. Ультразвук
закрывает заблокированный участок, робот возвращается к предыдущему узлу
и перепланирует маршрут по боковому проезду. В целевой парковке требуется
свежий кадр именно с заданной меткой. Стартовое место передаётся только Webots.
Модель имеет дифференциальные колёса, энкодеры, IMU, обычную камеру и
передний сонар. Эталонную позу Webots читает только проверка результата.
JSON сохраняет фактический и распознанный старт, результат, время,
зазор, факт контакта и отклонение от центра парковки.

Прогон всех направленных пар в контейнере:

```bash
./verify.sh "$PWD/results/matrix" blocked
./verify.sh "$PWD/results/matrix-clear" clear
```

ROS-интерфейсы `/cmd_vel` (Twist), `/odom` (Odometry) и
`/front_camera/image_raw` (Image) сверены с документацией TurtleBro2.
`/ultrasonic/front` (Range) введён для симуляции. Имя можно поменять
через `navigate.py --sonar`. Для реальной машины нужны карта и ID вашего
поля, горизонтальный FOV камеры, фактический топик ультразвука и проверка
старта с меткой в кадре. Повороты и реверс проверялись только в симуляторе.
Опубликованная документация производителя описывает конфигурацию с Jazzy,
а этот контейнер использует Humble.
